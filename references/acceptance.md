# 验收与已知边界

本版为 0.2.0-alpha：带默认聊天沉淀和会议整理流程，简易初始化 Skill；不是已验证的新电脑一键安装器。

- init 两次不得覆盖既有用户资料。
- 非白名单、群聊、机器人发送的事件被忽略。
- 重复 message_id 不重复调用模型或追加备忘；发送失败重试复用结果。
- 附件不伪装成已读，明确仅支持文字。
- 两条默认流程按原文版本缓存，重复输入不重新总结或发送，同日新增可处理；六套旧通用模板仍按日缓存。preview 不写正式运行状态、不发送、不转写音频。
- enabled=false 的模板不执行，未知模板拒绝。
- config.json、凭据、真实工作目录、日志和聊天记录不得发布。

发布前的自动测试不调用真实模型或发送消息。使用者仍需完成模型登录、飞书授权、文字往返、真实工作产物、宿主定时触发和暂停恢复的端到端验证。

远程入口采用模型只读运行，程序仅追加备忘及保存结果；不宣称支持任意系统操作。模型接收的是指定目录内 Markdown，内容可能发送到用户配置的模型服务。不要放入不希望提供给该服务的材料。只读沙箱不等于文件读取隔离；需要强隔离时使用独立系统账号或容器。

普通问答限制：读取 profile.md、AGENTS.md、inbox/、notes/，合计最多 40000 字符、每文件最多 12000 字符，截断时提示。默认整理流程独立按片段完整读取 chats/ 与会议逐字稿，不受普通问答截断影响。跳过 symlink 与越界文件。

新增验收：保存本人对话原文与回复；导入聊天不重复；同日新增和昨晚补查；长逐字稿全片段处理；缺少转写器不上传音频且列为待处理；模拟转写后逐字稿缓存复用；一份失败不阻断其他输入。真实 ASR、微信插件、模型总结准确率与调度端到端验证仍未完成。

微信官方已有 OpenClaw 插件路径，但本包没有集成该网关。Facebook、多用户、精确提醒、开机自启、跨平台全量历史自动采集尚未实现。会议转写须先接通实际转写器，不是内附账号和免费 ASR。
